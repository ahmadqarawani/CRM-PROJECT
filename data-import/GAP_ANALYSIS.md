## 2) مراحل الإكساء (مختلفة عن الـ seed عنا)

**قرار أحمد:** جديد ← إرسال الكتالوج ← معاينة مجانية ← دراسة (مخططات + كلفة) ← جلسة اتفاق وعقد ← تنفيذ ← تسليم، **أو خسارة مع سبب**.

**أسباب الخسارة (قائمة):**
- السعر غالي / الميزانية قليلة
- استفسر وانقطع
- خارج منطقة الخدمة
- خدمة لا نقدمها
- اختار شركة أخرى
- إزالة بطلب الإدارة

**حقول طلب الإكساء:**
- نوع الخدمة: اكساء كامل (عضم)، تجديد/إعادة اكساء، تعديل وإعادة تقسيم، أعمال جزئية
- مستوى الإكساء: اقتصادي، ديلوكس، سوبر ديلوكس
- المحافظة والمنطقة، ونوع العقار، والمساحة م²، وحالة العقار
- الميزانية (من–إلى) **بالدولار بس**
- الأهمية: عالية / متوسطة / منخفضة
- **مهندس المعاينة** (رند/أمير)، وموعد المعاينة ونتيجتها
- تاريخ إرسال الدراسة، و**قيمة العرض** وملفات المخططات، وملاحظات ما بعد الدراسة
- موعد الاتفاق ونتيجته، و**قيمة العقد**
- **الدفعات** (المدفوع والباقي)، وبداية التنفيذ، والتسليم المتوقع

## 3) حقول العقار (موافق عليها)

- **التعريف والتصنيف:**
  - كود تلقائي، ومعه الكود القديم إذا موجود
  - النوع: شقة، دوبلكس، منزل عربي، منزل/فيلا، محل، مكتب، معمل/مستودع، أرض، بناء كامل
  - بيع أو إيجار
- **المكان:** المحافظة والمنطقة، والعنوان التفصيلي، ورابط الخريطة
- **الوصف:**
  - المساحة، وعدد الغرف والحمامات
  - الطابق: قبو، أرضي، 1..N، أكتر من طابق
  - إضافات (اختيار متعدد): شرفة، تراس، حديقة، سطح، قبو، فسحة سماوية
- **الحالة والإكساء:**
  - حالة البناء: قيد الإنشاء، جديد، مستخدم
  - مستوى الإكساء: عضم، كسوة قديمة، عادية، جيدة، ديلوكس، سوبر ديلوكس. **هي نفس القائمة لكل الأقسام.**
- **السعر:**
  - بالدولار، مع وحدة السعر: إجمالي / للمتر / للدونم
  - سعر بيع وإيجار شهري
  - قابل للتفاوض
- **الملكية:** طابو أخضر، حكم محكمة، كاتب عدل، طابو زراعي، عقد بيع
- **صفة المتواصل:** مالك، وكيل، وسيط، قريب المالك
- **وصف ومرفقات:** المميزات، والوصف، والصور والمخططات (رفع ملفات)
- **الإدارة:** المالك (عميل)، والموظف المسؤول، وتاريخ العرض، والحالة (متاح / محجوز / مباع-مؤجر)، ونسبة العمولة
- **عند الإغلاق:** السعر النهائي، والعمولة، والشاري أو المستأجر (عميل)
