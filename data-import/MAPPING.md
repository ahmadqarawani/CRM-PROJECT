## 1) ملف العملاء الجدد → Client + Request (+ Activity / Task)

**الملف هاد مش "عملاء" بس. كل صف فيه طلب (lead) مع مرحلته.**

| عمود الإكسل | بيروح على | الحالة |
|---|---|---|
| اسم العميل | `Client.name` | ⚠️ **267 من 406 بدون اسم**، والموديل حالياً بيطلب الاسم |
| رقم العميل | `Client.phone` | ⚠️ صيغ كتيرة (`0933…` و `933 …` و `963…` و `49 176…`)، و 5 خلايا فيها رقمين، و 5 أرقام مش صالحة |
| التاريخ | `Request.created_at` | ⚠️ 4 صيغ تواريخ (`2026/08/11` و `13/8/2026` و `0206/08/11`…) |
| نوع الخدمة | **ما إله مكان** | ❌ اكساء / استفسار / بيع / شراء / اجار. لازم حقل `Request.service` |
| المنطقة | **ما إله مكان** | ❌ لازم حقل `Request.area` (أو بالشقة) |
| نوع العقار ("شقة 105 م2") | `Request.title` + `description` | ✅ (نص حر) |
| الرنج السعري | `Request.budget` | ⚠️ فاضي أو `------` بـ 349 صف، والباقي نص ("40 مليون") ما بيدخل بحقل رقمي |
| حالة العميل | `Request.stage` | ✅ بمطابقة (تحت) |
| اهمية العميل Hot/Warm/Cold | `Request.priority` | ✅ HIGH / NORMAL / LOW |
| مصدر العميل | `Client.source` | ⚠️ "واتس م.دانا" هو مصدر **و** موظف، فمنفصلهم: المصدر = واتساب، والمسؤول = دانا |
| اخر تواصل | `Client/Request.last_contact_at` | ✅ (بعد توحيد التاريخ، وفي قيمة "لم يتم التواصل") |
| تاريخ المتابعة القادمة | `Request.next_follow_up_at` | ✅ (معبّى بـ 29 صف بس) |
| ملاحظات العميل | `Activity(NOTE)` | ✅ |
| موعد المعاينة + التوقيت + الحالة | `Task("معاينة")` + `Activity(VISIT)` إذا تمت | ✅ |
| حالة الدراسة + تاريخ الإرسال + الملاحظات | المرحلة "عرض سعر" + `Activity(NOTE)` بتاريخ الإرسال | ✅ |
| موعد / نتيجة الاتفاق | فاضيين بالكامل | — |
